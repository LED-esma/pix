# Roadmap

Pix's direction: the most dependable free helper a student can install on a Mac, with nothing to set up. Ideas and votes are welcome in [issues](https://github.com/LED-esma/pix/issues).

## Next

- **A stronger free experience.** The built-in AI and small models on your Mac do math, explaining and quick tasks well, but multi-step work (coding help, long website tasks) is much better on Claude. Closing that gap: fewer tools per question for small models, better hand-off down your AI list, and testing larger free models.
- **First-run testing on fresh Macs**: Intel, macOS 15, Apple Intelligence off, no Claude Code, so the first five minutes work for everyone.
- **Simpler by default.** Pix has many features; new users should meet a few, and find the rest when they look.
- **UI tests** that open the card, ask a question and check what's on screen, alongside the self-checks.

## Known issues

- On the built-in AI, a wrong setup still gives a wrong answer; Pix fixes the arithmetic, not the formula it picked.
- After Undo, the answer above it still describes the change.
- The card can sit over part of the app it's helping with; drag the blob to move it.
- Small models sometimes offer to do what a file asked for (Pix's rules still refuse to run it).

## Later

- **Windows**: the same blob, card and board. The engine, prompts, tools and board (web-based) carry over; windows, screen access and the shortcut need Windows versions (WinUI, or Tauri to share UI with the Mac app).
- **More languages** for the interface and for "Hey Pix".
